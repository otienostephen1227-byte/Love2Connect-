Build a modern, mobile-friendly worldwide dating website called Love2Connect. Project goal: Create a dating platform where adults aged 18 and above can register, create profiles, discover other members, like profiles, match with people who like them back, and chat privately. The website should eventually generate revenue through premium subscriptions and paid features. 1. Design - Use a modern, attractive design with purple, pink, white, and subtle gradients. - Display the Love2Connect name and a heart-themed logo. - Make the website responsive on Android phones, tablets, and computers. - Use clean navigation, attractive profile cards, and simple buttons. - Make the interface professional and easy to use. 2. Main pages Create the following pages: - Home page with a welcome message and Join Now button. - Sign-up and login pages. - Member profile creation and editing page. - Discover page with member profile cards. - Likes and mutual matches page. - Private messaging page. - Premium membership and pricing page. - Settings, report, block, and account deletion pages. 3. User profiles Members should be able to add their display name, age, country, interests, biography, and profile photos. Only adults aged 18 or older may register. Allow members to edit their profiles and control their privacy. 4. Likes and matching Allow a member to like another profile. Create a match only when both members have liked each other. Do not allow a member to like their own profile. 5. Private messaging Allow matched members to exchange private messages. Messages must be accessible only to authorized participants. Include blocking and reporting features. 6. Premium membership Create a premium page with monthly and annual subscription options. Show premium benefits such as advanced filters and additional likes. Include a clear pricing interface, but do not pretend that payments work until a payment provider is integrated and tested. 7. Technology - Use HTML, CSS, and JavaScript, or a suitable modern framework. - Use Supabase for authentication, database storage, and profile photo storage. - Configure database security policies so members can access only the data they are authorized to see. - Prepare the website for deployment on Netlify with a free Netlify subdomain. - Keep API keys and secrets out of public source code. 8. Safety and security Include adult-only registration, privacy controls, report and block functions, secure authentication, and account deletion. Never expose passwords, private messages, or private user information publicly. Use fictional sample profiles during development. 9. Development instructions Build the project step by step. Start with a working homepage and responsive navigation. Then implement registration, profiles, matching, messaging, and premium membership. Explain which files to create and provide the complete code for each file. Do not claim that a feature is operational until it has been implemented and tested. Clearly identify any configuration or payment integration that still needs to be completed. Final objective: Deliver a functional, secure, mobile-friendly Love2Connect dating website that can start on free hosting and later scale as its membership grows.
